# VedaCA 测试版预览

VedaCA 是尚未实机验证、由用户主动启用的飞字观察辅助，适用于 Dalamud API 15 参考构建。7.57 与 7.58 的设备和运行环境尚未实机验证；游戏更新后需框架提供支持，不承诺全兼容或保证安全。

默认停用。主动启用后，仅在有界内存中观察 kind、val1 原始数值及本地序号，不含 ActionId，没有本人过滤，也没有音效；不能保证本人输出或完整事件覆盖。插件不读取姓名与飞字文本，但框架可能独立处理这些信息。原生 ActionEffect 路径保持关闭。可停止观察并清空数据；启用失败时可重试。无记录文件或网络功能。

## 安装与观察

以下步骤以自定义源及 ZIP 可用、框架支持当前游戏版本为前提：

1. 在 Dalamud 设置中添加自定义插件源： https://raw.githubusercontent.com/Coptone/VedaCA/main/pluginmaster.json
2. 搜索 VedaCA 并安装。
3. 在游戏内输入 `/vedaca`。
4. 主动启用观察，然后对照游戏中的飞字查看 kind 和 val1。
