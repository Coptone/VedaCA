# 下一阶段国服只读 PoC 验收手册

状态：未执行。M1a 的合成测试不构成 M1 PoC 或国服验收。
目前未取得实际客户端/SDK 版本、字段布局和实机样本；不得填造。

1. 在获授权的实际游戏环境记录国服客户端完整构建号、Dalamud/API 版本、
   FFXIVClientStructs 版本/提交、实际 SDK 目标框架、架构、目录快照日期和校验摘要。
   本项目 net6.0 仅离线使用。找不到匹配 SDK 时停止，不下载新 API 替代、不创建假游戏 DLL。
2. 依据该 SDK 核对回调签名、原函数调用规则、安装卸载生命周期及异常隔离。
   确认字段宽度、边界、伤害类型、严重度位置/位掩码、扩展伤害解码、目标/Owner、
   实际效果 ActionId、GlobalSequence 与回绕/会话重置语义。
   PRD 中 Param0 和标记位仅为待验证线索，不能照抄成已验证布局。
3. 适配器只在有效回调内复制有界值，不保留游戏指针、不 await、不做音频或磁盘工作。
   版本未知、布局验证未通过、来源身份无法确认时保持失败关闭。
   离线 SyntheticVerified 工厂不得用来批准真实版本。真实批准机制须另行实现并审查。
4. 木桩分别采集普通、仅暴击、仅直击、直击暴击四类样本，记录同一效果的
   动作/序列/目标/效果索引/伤害/标记与游戏飘字或录屏对照。
   每类至少留存可复现原始字段及独立观察结论；样本数量和时间由实际执行填写，
   不以伤害阈值、按键或动画推测结果。
5. 验证本机与他人同技能、宠物、PvP、友方、治疗、DoT、反伤、零伤害/免疫、
   取消/打空、未选职业动作均不成为候选。分开的目标或效果各一个标记不能拼成直爆。
6. 专门记录 AOE 主目标、自中心无敌方动画主目标、重复回调、分包、多效果和变体
   的原始关联证据。核对同一施放身份是否跨包稳定；只有证实后才能设计归并及有界
   TTL 去重。不能用 100ms 窗口。当前 M1a 未完成这些规则。
7. 对快速独立施放（含同动作合法独立施放）、相邻 GCD/能力技、会话切换、
   GlobalSequence 回绕分别举证，确保不误吞。骑士五剑必须独立判断，不能合并整套。
8. 首批骑士五剑、贤者两招、白魔苦难之心逐项确认实际效果 ID 与四类结果；
   低阶替换和派生映射单独验证，不把公开资料当实测。黑魔三招默认保留的产品要求
   留待目录阶段；本次无职业预设。
9. 主动导出样本前脱敏身份并限制数量，记录本地证据路径和摘要，不上传。
   未验证前保持游戏监听和音频关闭；本项目本身没有安装 Hook 的代码。
10. 四类结果、归属、版本和施放证据通过审核后再进入后续阶段：
    本地音频试听；纯规则会话/倍率/去重；真实事件联通；首批职业验收；再扩目录。
    音频的 15 秒/12 秒淡出、打断重播、按接纳播放请求计数等仍属后续范围。

验收表每行必须填写实际版本、样本路径、期望、观察、通过/失败及复核人。
缺证据填写“未验证”，不填写“通过”。编译和离线测试不能替代实机验收。
